Kod hazır. Gizlilik sayfası hazır. Sizin işiniz hesap ve haftalık kapak.

## Bugün (bir kez)

1. github.com → ücretsiz hesap (yoksa)
2. Yeni repo: `offerweek-kenya` → Public
3. `kenya-weekly` klasörünün içini bu repoya yükleyin
   (Upload files veya GitHub Desktop. Komut yazmak zorunda değilsiniz.)
4. vercel.com → Continue with GitHub → Import `offerweek-kenya` → Deploy
5. Çıkan URL’yi kaydedin. Bana gönderin.

Alan adı şart değil. İlk hafta Vercel adresi yeter.
